Phase 1-F7 최종 점검 전에 `/home-v2`의 시각적 배치 기준을 먼저 고정합니다.

현재 우려되는 점은 Replit이 로고, 버튼, 검색창, 카테고리 탭 등을 주변 요소의 비율로 맞추면서, 하나를 수정하면 다른 요소가 같이 밀리는 구조가 생기는 것입니다.

이번 점검에서는 기능보다 **레이아웃 기준선**을 먼저 확인하세요.

## 1. 핵심 원칙

`/home-v2`의 헤더, 검색창, 카테고리 탭, 버튼 배치는 비율 감각으로 조정하지 말고 아래 기준으로 고정합니다.

1. 전체 화면 기준이 아니라 중앙 컨테이너 기준으로 정렬
2. 모든 주요 섹션은 같은 좌우 여백 기준 사용
3. PC 기준 최대 폭은 `max-w-6xl` 또는 1100~1200px 유지
4. 모바일 기준 좌우 여백은 `px-4` 유지
5. 로고, 검색창, 버튼이 서로 밀고 당기지 않게 영역 역할을 분리
6. 한 요소 수정 시 다른 요소 위치가 같이 흔들리지 않게 최소/최대 폭 지정
7. 임의의 `justify-between` 남발 금지
8. 임의의 `w-full`, `flex-1`, `ml-auto`, `gap` 조합으로 끝단에 몰아넣는 방식 금지
9. 시각적 기준선은 로고, 검색창, 카드 섹션이 같은 컨테이너 라인에 맞아야 함

---

## 2. 헤더 배치 기준

헤더는 다음 구조를 기준으로 점검하세요.

```text
header
└── inner container: max-w-6xl mx-auto px-4
    ├── left: logo area
    ├── center: search area
    └── right: action buttons
```

### PC 기준

1. 로고 영역은 왼쪽 고정
2. 검색창은 중앙에서 적당한 최대 폭 유지
3. 로그인/광고접수 버튼은 오른쪽에 있되 화면 끝에 과하게 붙지 않음
4. 세 영역은 같은 높이 기준으로 수직 중앙 정렬
5. 버튼 때문에 검색창이 과하게 줄어들지 않도록 검색창 max-width 지정
6. 버튼 영역은 내용 크기만큼만 차지

### 모바일 기준

모바일에서는 억지로 한 줄에 모두 넣지 마세요.

권장 구조:

```text
1행: 로고 + 로그인/광고접수 버튼
2행: 검색창
3행: 카테고리 탭
```

또는 현재 구조를 유지하되, 360px에서 다음을 확인하세요.

1. 로고가 너무 왼쪽 끝에 붙지 않는지
2. 광고접수 버튼이 오른쪽 끝에 붙어서 답답하지 않은지
3. 검색창이 너무 작아지지 않는지
4. 버튼 때문에 검색창이 밀리지 않는지
5. 헤더 높이가 과도하게 커지지 않는지

---

## 3. 검색창 기준

검색창은 주변 요소에 따라 폭이 흔들리면 안 됩니다.

기준:

1. PC에서는 `max-w-md` 또는 `max-w-lg` 수준
2. 모바일에서는 컨테이너 안에서 `w-full`
3. 로고와 버튼 사이에 끼워 넣어 억지로 줄이지 말 것
4. 검색창 높이는 최소 40px 이상
5. X 버튼 터치 영역은 최소 36~44px 확보
6. 검색창 좌우 위치는 카드 섹션의 좌우 기준선과 어긋나지 않게 할 것

---

## 4. 카테고리 탭 기준

카테고리 탭은 헤더나 검색창의 폭에 종속되면 안 됩니다.

기준:

1. 같은 `max-w-6xl mx-auto px-4` 컨테이너 안에 배치
2. 모바일에서는 가로 스크롤 허용
3. 탭 버튼 최소 높이 44px 유지
4. 첫 번째 탭이 화면 왼쪽 끝에 붙지 않도록 컨테이너 padding 유지
5. 스크롤 영역이 카드 섹션보다 넓거나 좁아 보이지 않게 정렬
6. 탭 간격은 일정하게 유지

---

## 5. 섹션 기준선

아래 섹션들은 모두 같은 좌우 기준선을 사용해야 합니다.

1. 오늘의 강릉소식
2. 소상공인 추천
3. 광고문의 배너
4. 강릉노트
5. 푸터

모든 섹션은 다음 구조를 따르세요.

```tsx
<section className="mx-auto max-w-6xl px-4">
  ...
</section>
```

또는 상위 wrapper 하나에서 동일 기준을 제공하세요.

섹션마다 서로 다른 `px`, `max-w`, `ml`, `mr` 값을 임의로 주지 마세요.

---

## 6. 금지할 레이아웃 패턴

아래 방식은 피하세요.

1. 화면 끝에 붙이기 위해 `absolute right-0` 사용
2. 로고와 버튼을 양끝에 붙이기 위해 무조건 `justify-between` 사용
3. 검색창에 무조건 `flex-1`을 주고 버튼 크기에 따라 흔들리게 만들기
4. 모바일에서 로고, 검색창, 버튼을 억지로 한 줄에 넣기
5. 특정 화면폭에서만 맞는 `ml-10`, `mr-12` 같은 임의 여백 사용
6. 섹션별로 다른 max-width 사용
7. 전역 CSS로 헤더를 강제로 보정
8. 별도 CSS 파일 생성
