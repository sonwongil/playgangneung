# Phase 1-F2 승인 범위

## `/home-v2` 소상공인 추천 카드 섹션 추가

이번 단계의 목표는 `/home-v2` 안에 소상공인 추천 카드 섹션을 추가하는 것입니다.

PLAY강릉은 단순한 지역 소식 사이트가 아니라
강릉 소상공인의 온라인 마케팅을 돕는 플랫폼입니다.

따라서 새 홈 구조는 다음 순서가 되어야 합니다.

1. 오늘의 강릉소식
2. 소상공인 추천
3. 강릉노트 피드

이번 단계는 기존 `/` 홈 교체가 아닙니다.
기존 `home.tsx` 수정이 아닙니다.
광고 신청 기능 구현이 아닙니다.
결제 기능 구현이 아닙니다.
Meta 광고 기능 구현이 아닙니다.

오직 **`/home-v2` 안에 소상공인 추천 카드 섹션을 읽기 전용으로 추가**하는 작업입니다.

---

## 1. 허용 작업

다음 작업만 허용합니다.

1. `HomeV2Page.tsx` 안에 소상공인 추천 섹션 추가
2. 기존 `GET /api/ads/premium-featured` 사용
3. 읽기 전용 GET만 사용
4. 소상공인 추천 카드 3~6개 표시
5. 카드에는 업체명, 이미지, 카테고리, 설명, 배지 표시
6. 클릭 시 기존 광고 상세 방식이 불명확하면 우선 클릭 동작 없이 placeholder 처리
7. 또는 안전한 내부 링크가 이미 있으면 그 링크만 사용
8. 섹션 제목은 “강릉 소상공인 추천” 또는 “소상공인 추천” 사용
9. 오늘의 강릉소식 아래, 강릉노트 피드 위에 배치
10. typecheck 실행
11. build 실행

### 소상공인 추천 카드 표시 항목

가능한 데이터만 사용하세요.

1. 이미지
2. 업체명 또는 제목
3. 카테고리
4. 설명
5. 프리미엄/추천/광고 배지
6. 자세히 보기 버튼 또는 placeholder

데이터 필드명이 불명확하면 구현 전에 기존 `/api/ads/premium-featured` 응답 구조를 먼저 확인하고, 그 구조에 맞춰 표시하세요.
