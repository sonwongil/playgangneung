PLAY강릉 프로젝트의 다음 핵심 작업은
“행사정보 크롤링 → 일정 안착 → 관리자 검수 → 공개 피드 반영”
구조를 완성하는 것이다.

현재 프로젝트 상태:
- React + Vite 프론트
- Express 백엔드
- 공개 메인 피드 존재
- 행사 탭 + 서브탭 존재
- 광고접수 시스템 존재
- SNS 반자동 발행 구조 존재
- /content/:id 상세페이지 존재
- 카드 생성 및 SNS 초안 기능 존재

목표:
강릉 및 강원권 행사/지역소식 데이터를 자동 수집하여,
PLAY강릉의 일정 플랫폼 + SNS 콘텐츠 소스로 활용한다.

-----------------------------------
1. 크롤링 대상 추가
-----------------------------------

우선 크롤링 대상:

1. 강릉시청
- 행사/축제
- 공지사항
- 문화행사

2. 강릉문화재단
- 공연
- 전시
- 축제

3. 강원신문
- 강릉 관련 뉴스
- 행사
- 문화
- 관광
- 지역소식

4. 강원도민일보
- 강릉/동해안 뉴스
- 축제
- 행사
- 관광
- 지역 이슈

5. 한국관광공사 지역 행사 RSS 또는 API 가능 시 활용

-----------------------------------
2. 크롤링 방식
-----------------------------------

가능하면 우선순위:

1. RSS
2. HTML 크롤링 (cheerio)
3. fallback parser

사용 기술:
- axios
- cheerio

타임아웃:
- 사이트별 timeout 설정
- 실패 시 앱 전체 중단 금지

중요:
크롤링 실패해도 서버는 정상 동작 유지.

-----------------------------------
3. 이벤트 데이터 구조 통합
-----------------------------------

모든 크롤링 결과를 아래 구조로 통합:

{
  id,
  type: "event",
  title,
  description,
  category,
  source,
  sourceUrl,
  thumbnail,
  startDate,
  endDate,
  displayDate,
  scheduleStatus,
  location,
  createdAt,
  crawledAt,
  status,
  socialDraft,
  cardImageUrl
}

-----------------------------------
4. 날짜 파싱 및 일정 안착
-----------------------------------

date 문자열에서:
- startDate
- endDate
자동 추출.

예:
"2026.05.01 ~ 2026.05.03"

→
startDate: 2026-05-01
endDate: 2026-05-03

자동 계산:
today
tomorrow
ongoing
upcoming
ended

날짜 인식 실패 시:
scheduleStatus: "dateUnknown"

-----------------------------------
5. 중복 제거
-----------------------------------

다음 기준으로 중복 검사:
- title
- source
- startDate

유사 이벤트는 병합 또는 skip.

① 승인

③ 카드이미지
④ 발행완료

-----------------------------------
10. 행사달력 구현
-----------------------------------

/calendar 또는 행사 내부 서브뷰

요구사항:
- 월간 달력
- 행사 있는 날짜 파란 점 표시
- 날짜 클릭 시 해당 날짜 행사 목록 표시
- 오늘 날짜 강조
- 종료 행사 흐리게 표시

가능하면 react-calendar 활용.

-----------------------------------
11. 공개 피드 노출 조건
-----------------------------------

approved 또는 published 상태만 공개.

pending/rejected/dateUnknown 제외.

정렬:
1. 프리미엄 광고
2. 메인 광고
3. 오늘 행사
4. 진행중 행사
5. 최신 행사

-----------------------------------
12. 상세 페이지 연결
-----------------------------------

모든 공개 콘텐츠는:
SITE_URL/content/:id

상세 페이지 제공.

Meta 인앱 브라우저 최적화:
- 빠른 로딩
- Open Graph
- 로그인 불필요
- 새창 없음

-----------------------------------
13. SNS 초안 자동 생성
-----------------------------------

SNS 초안 마지막에 반드시:

👉 자세히 보기:
SITE_URL/content/{id}

자동 포함.

문구 유형:
- 인스타용 (짧고 감성)
- 페북용 (정보형)

복사 버튼 제공.
