# Phase 1-F6 승인 범위

## `/home-v2` 교체 전 필수 보정 2개

이번 단계의 목표는 `/home-v2`를 메인 홈 후보로 보기 위해 반드시 필요한 최소 보정만 하는 것입니다.

이번 단계는 `/` 교체가 아닙니다.
이번 단계는 기존 `home.tsx` 수정이 아닙니다.
이번 단계는 광고 신청 기능 구현이 아닙니다.
이번 단계는 결제/Meta/SNS 기능 연결이 아닙니다.

오직 `/home-v2` 안에서 아래 2가지만 보정합니다.

1. 공식 사업자 푸터 추가
2. Clerk 로그인/회원가입 버튼 또는 광고접수 진입 버튼 추가

---

## 1. 허용 작업

다음 작업만 허용합니다.

1. `HomeV2Page.tsx`만 수정
2. `/home-v2` 하단에 공식 사업자 푸터 추가
3. 기존 홈의 사업자 정보 문구를 확인해서 동일하거나 간결하게 반영
4. 헤더 우측 또는 상단 메뉴에 로그인/회원가입/광고접수 진입 버튼 추가
5. Clerk 상태 확인이 꼭 필요하면 기존 홈의 Clerk 사용 방식만 참고
6. 로그인 상태에 따라 최소 표시만 구현
7. typecheck 실행
8. build 실행

---

## 2. 공식 사업자 푸터 기준

기존 홈에 있는 공식 사업자 정보를 확인해서 누락 없이 반영하세요.

필수 항목:

1. 상호
2. 대표자
3. 사업자등록번호
4. 주소
5. 이메일 또는 문의 연락처

표시는 간결하게 합니다.

예시:

```text id="pxp9i0"
PLAY강릉
상호: ○○○ | 대표: ○○○ | 사업자등록번호: ○○○
주소: ○○○
문의: ○○○
```

사업자 정보가 코드에 이미 있으면 기존 내용을 그대로 사용하세요.
새 정보를 추측하거나 임의로 만들지 마세요.

---

## 3. 로그인/회원가입/광고접수 버튼 기준

기존 홈의 Clerk 로그인 흐름을 확인하고, `/home-v2`에는 최소 버튼만 추가하세요.

권장 방식:

### 미로그인 상태

1. 로그인
2. 회원가입
3. 광고접수

### 로그인 상태

1. 내 광고
2. 광고접수
3. 로그아웃

다만 이번 단계에서는 복잡한 드롭다운이나 모달을 만들지 마세요.

버튼 클릭 경로는 기존 홈에서 사용하던 안전한 경로를 그대로 사용하세요.

예상 경로:

```text id="s7xdgh"
/ad-submit
/my-ad
```

로그인/회원가입은 기존 Clerk 방식 사용.

## 5. UI 원칙

다음 기준을 지키세요.
