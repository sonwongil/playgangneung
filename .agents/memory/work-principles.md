# 작업 원칙 (2026-06-01 합의)

## 재발한 문제
- 오전에 `proxyImg` 함수를 불필요하게 수정 → 직접 올린 이미지가 proxy 400 에러로 안 뜨는 문제 발생
- 요청하지 않은 코드를 건드려 새 버그를 만들고, 오후에 다시 고치는 악순환

## 재발 방지 원칙

### 1. 수정 전 반드시 현재 코드 확인
- 파일을 먼저 읽고, git으로 내가 최근에 건드린 게 있는지 확인한 후 수정한다

### 2. 범위 최소화
- 요청한 것만 고친다
- 잘 되고 있는 코드는 절대 건드리지 않는다

### 3. 수정 전 영향 범위 먼저 고지
- "이 파일의 이 부분만 바꿉니다"를 먼저 말하고 진행한다

**Why:** 사용자가 하루 종일 제가 만든 문제를 디버깅하느라 시간을 낭비했음. 이미 작동하는 건 손대지 않는 것이 최우선 원칙.
