# Phase 1-F9 승인 범위

## 메인 홈 교체 후 최종 검증 및 롤백 기준 정리

이번 단계의 목표는 `/`가 새 홈으로 교체된 상태에서 핵심 경로가 정상인지 확인하고, 문제가 생겼을 때 `/home-legacy`로 되돌릴 수 있는 기준을 정리하는 것입니다.

이번 단계는 새 기능 구현이 아닙니다.
운영 배포가 아닙니다.
GitHub push가 아닙니다.
PWA 수정이 아닙니다.

오직 **검증과 보고**만 진행합니다.

확인할 것:

2. 기존 TOP5 표시

## 4. 롤백 기준 정리

문제가 발생하면 `/`를 다시 기존 홈으로 되돌릴 수 있어야 합니다.

롤백 기준을 보고하세요.

예시:

```text
아래 중 하나라도 발생하면 즉시 롤백:
1. `/` 접속 불가
2. 홈에서 카드 클릭 불가
3. `/content/:id` 이동 불가
4. 로그인/광고접수 진입 불가
5. 모바일 화면 주요 영역 깨짐
6. build/typecheck 실패
```

롤백 방식도 제안하세요.

예상 롤백:

```tsx
<Route path="/" component={Home} />
<Route path="/home-v2" component={HomeV2Page} />
<Route path="/home-legacy" component={Home} />
```
