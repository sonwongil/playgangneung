# Phase 1-H 승인 범위

## VPS 운영 반영 전 백업 및 안전 배포

이번 단계의 목표는 GitHub main에 올라간 새 홈 작업을 VPS 운영 서버에 안전하게 반영하는 것입니다.

이번 단계에서는 nginx, DNS, SSL, DB, ecosystem.config.cjs를 수정하지 않습니다.
DB 마이그레이션도 실행하지 않습니다.
PWA 설정도 수정하지 않습니다.

오직 아래 순서로만 진행합니다.

---

## 1. 운영 서버 현재 상태 확인

VPS에서 먼저 현재 상태를 확인하세요.

```bash id="qvbdtp"
cd /var/www/playgangneung
pwd
git branch --show-current
git rev-parse HEAD
git status --short
pm2 status
```

보고할 것:

1. 현재 브랜치
2. 현재 커밋 해시
3. git status 상태
4. PM2 앱 이름
5. PM2 실행 모드
6. instances 값

중요:

`PM2`는 반드시 fork mode / instances 1 상태를 유지해야 합니다.
cluster mode 또는 instances 14로 되돌리지 마세요.

---

## 2. 배포 전 백업 생성

운영 반영 전에 현재 운영 소스 백업을 생성하세요.

예시:

```bash id="oxueo1"
cd /var/www
tar -czf /var/www/backups/playgangneung-before-homev2-$(date +%Y%m%d-%H%M%S).tar.gz playgangneung
```

백업 경로가 실제로 존재하는지 먼저 확인하고, 없다면 만들기 전에 보고하세요.

```bash id="e7et6z"
ls -ld /var/www/backups
```

없으면:

```bash id="j9b6mh"
mkdir -p /var/www/backups
```

보고할 것:

1. 백업 파일명
2. 백업 파일 크기
3. 백업 생성 성공 여부

---
