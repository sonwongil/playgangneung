# Phase 1-F4 승인 범위

## `/home-v2` 모바일 사용성 점검 및 경미한 UI 보정

이번 단계의 목표는 `/home-v2`가 모바일에서 편하게 보이는지 확인하고, 필요한 경우 경미한 UI 보정만 하는 것입니다.

이번 단계는 홈 교체가 아닙니다.
기존 `/` 홈 수정이 아닙니다.
PWA 수정이 아닙니다.
새 기능 구현이 아닙니다.

오직 **`/home-v2` 모바일 사용성 점검과 경미한 UI 보정**까지만 진행합니다.

---

## 1. 점검할 것

다음을 확인하세요.

1. 모바일 화면 폭 360px 기준에서 깨지는 영역이 있는지
2. 검색창이 너무 작거나 잘리지 않는지
3. 카테고리 탭이 가로 스크롤로 자연스럽게 동작하는지
4. 오늘의 강릉소식 카드가 좌우로 잘 넘겨지는지
5. 소상공인 추천 카드가 너무 작거나 글자가 잘리지 않는지
6. 광고문의 배너가 과하게 크지 않은지
7. 강릉노트 카드가 모바일에서 1열 또는 2열 중 어떤 구성이 더 편한지
8. 카드 클릭 영역이 최소 44px 이상인지
9. 이미지 비율이 깨지지 않는지
10. 하단 여백이 충분한지
