Phase 1-H는 VPS SSH에서 직접 실행합니다.

오늘은 아래 순서만 진행합니다.

---

# STEP 1 — VPS 현재 상태 확인

```bash id="nh5sa2"
cd /var/www/playgangneung
pwd
git branch --show-current
git rev-parse HEAD
git status --short
pm2 status
```

확인할 것:

```text id="x96nb0"
브랜치: main
git status: 비어 있거나 문제 없는 상태
PM2 앱 이름: playgangneung
PM2 mode: fork
PM2 instances: 1
```

여기서 이상하면 다음 단계로 가지 말고 보고하세요.

---

# STEP 2 — 배포 전 백업

```bash id="xhicqq"
ls -ld /var/www/backups 2>/dev/null || mkdir -p /var/www/backups

tar -czf /var/www/backups/playgangneung-before-homev2-$(date +%Y%m%d-%H%M%S).tar.gz \
  --exclude='/var/www/playgangneung/node_modules' \
  --exclude='/var/www/playgangneung/.pnpm-store' \
  -C /var/www playgangneung

ls -lh /var/www/backups/ | tail -5
```

확인할 것:

```text id="2mc7tc"
백업 파일명
백업 파일 크기
백업 생성 시간
```

---

# STEP 3 — GitHub 최신 코드 반영

```bash id="a2gdg9"
cd /var/www/playgangneung
git fetch origin main
git log --oneline HEAD..origin/main
```

여기서 반영될 커밋 목록을 확인합니다.

이상 없으면:

```bash id="gfzbtb"
git pull origin main
git rev-parse HEAD
```

확인할 것:

```text id="q4x4pn"
최신 커밋이 28c8b71 로 시작하는지
충돌이 없는지
git pull 성공했는지
```

# STEP 4 — 빌드

```bash id="hyf91f"
pnpm --filter @workspace/api-server --filter @workspace/playgangneung-dashboard run build
```

중요:

```text id="4lytdo"
빌드 성공 시에만 STEP 5 진행
빌드 실패 시 PM2 restart 금지
```

# STEP 5 — PM2 재시작

먼저 앱 이름 확인:

```bash id="wkfvce"
pm2 status
```

앱 이름이 `playgangneung`이 맞으면:

```bash id="z0mhza"
pm2 restart playgangneung
pm2 status
```

확인할 것:

```text id="pk74mq"
앱 상태: online
mode: fork
instances: 1
```
