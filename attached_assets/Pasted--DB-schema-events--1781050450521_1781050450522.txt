분석 결과 확인했습니다.

이제 강릉노트 보기 페이지 다음 단계로, 관리자 편집 기능을 개선합니다.

이번 작업 목표는 DB schema 변경 없이, 이미 events 테이블에 존재하는 필드를 관리자 새 피드 등록/수정 화면에서 제대로 입력·수정할 수 있게 만드는 것입니다.

우선순위는 다음과 같습니다.

1. contact 수정 버그 해결

현재 이벤트 수정 다이얼로그에는 문의처 UI가 있지만 PATCH 전송 코드에서 contact가 누락되어 있습니다.
수정 저장 시 contact가 정상 반영되도록 patch payload에 contact를 포함해 주세요.

2. 기존 이벤트 수정 폼에 원본 링크 link 필드 추가

현재 새 피드 등록에는 원본 링크 입력이 있지만, 기존 이벤트 수정 폼에는 없습니다.
수정 폼에서도 link를 수정할 수 있게 해 주세요.

이 필드는 강릉노트의 “원본 보기” 버튼과 SEO 출처 흐름에 중요합니다.

3. 기존 이벤트 수정 폼에 출처/업체명 source 필드 추가

현재 새 피드 등록에는 출처/업체명 입력이 있지만, 기존 이벤트 수정 폼에는 없습니다.
수정 폼에서도 source를 수정할 수 있게 해 주세요.

source는 강릉노트 핵심 정보 카드와 SEO title 보강 조건에 사용됩니다.

4. extraImages URL 목록 편집 UI 추가

events 테이블에는 extraImages jsonb 필드가 있고, PATCH /api/events/:id도 extraImages를 지원합니다.
그러나 관리자 UI에는 편집 기능이 없습니다.

수정 폼에서 추가 이미지 URL을 여러 개 입력/수정/삭제할 수 있게 해 주세요.

권장 UI:

* 추가 이미지 URL 목록
* URL 추가 버튼
* 각 URL 삭제 버튼
* 저장 시 extraImages 배열로 PATCH 전송

파일 업로드는 이번 단계에서는 하지 말고, URL 입력 방식부터 구현해 주세요.

5. 이벤트 기본 hashtags 편집 기능 추가

events 테이블에는 hashtags jsonb 필드가 있지만, 현재 PATCH /api/events/:id 파라미터에는 없습니다.
PATCH에서 hashtags를 받을 수 있게 추가하고, 수정 폼에서 해시태그를 입력/수정할 수 있게 해 주세요.

주의:

* socialDraft.hashtags와 events.hashtags는 별도입니다.
* 강릉노트 표시 기준은 events.hashtags 우선, 없으면 socialDraft.hashtags fallback을 유지해 주세요.
* 이번 작업은 events.hashtags를 직접 관리할 수 있게 하는 것입니다.

권장 UI:

* 쉼표 구분 입력 또는 태그 입력 방식
* 예: 강릉행사, 가족체험, 주말나들이
* 저장 시 string[] 배열로 변환

6. videoUrl 기존 기능 유지 확인

수정 폼의 동영상 URL 입력과 저장 흐름이 깨지지 않게 해 주세요.
강릉노트에서 videoUrl이 정상 표시되는지도 확인해 주세요.

7. 카드 이미지 재생성 흐름 확인

thumbnail 또는 extraImages를 수정하면 기존 카드 이미지가 오래된 이미지일 수 있습니다.
이번 단계에서는 자동 재생성까지 무리하게 하지 말고, 최소한 다음 중 하나를 확인해 주세요.

* 저장 후 기존 POST /api/events/:id/card 수동 재생성 버튼이 있는지
* 없다면 관리자에서 카드 이미지 재생성 버튼을 추가할 수 있는지 검토
* 이번 작업에서는 검토 보고까지만 해도 됩니다.

작업 범위 제한:

* DB schema 변경하지 마세요.
* reservation_url, opening_hours, price, recommend_reason, link_mode, approved_at 필드는 아직 추가하지 마세요.
* 파일 업로드 기능은 이번 단계에서 구현하지 말고, extraImages URL 편집부터 구현해 주세요.
* 광고 카드 기존 동작은 건드리지 마세요.
* /viewer는 삭제하지 마세요.
* draft 콘텐츠를 일괄 승인하지 마세요.

검증 요청:

작업 후 아래를 확인해 주세요.

1. TypeScript 체크 통과
2. scripts/validate.sh 통과
3. 기존 이벤트 수정 시 contact가 저장되는지 확인
4. 기존 이벤트 수정 시 link가 저장되는지 확인
5. 기존 이벤트 수정 시 source가 저장되는지 확인
6. extraImages URL 목록을 추가/삭제/저장할 수 있는지 확인
7. 저장된 extraImages가 강릉노트 이미지 슬라이더에 표시되는지 확인
8. hashtags를 수정하면 강릉노트 해시태그 배지에 반영되는지 확인
9. videoUrl 기존 동작이 깨지지 않았는지 확인
10. SNS 초안 편집 기능이 깨지지 않았는지 확인
11. 광고 카드 기존 동작이 깨지지 않았는지 확인

이번 작업의 목표는 강릉노트를 “보기 좋은 상세 페이지”에서 “관리자가 실제로 다듬을 수 있는 콘텐츠 자산”으로 발전시키는 것입니다.
