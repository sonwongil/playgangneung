# Phase 1-F1 승인 범위

## `/home-v2` 최소 홈 미리보기 구현

이번 단계의 목표는 기존 `/` 홈을 수정하지 않고,
새 홈 후보 화면을 `/home-v2` 경로에 별도로 만드는 것입니다.

이번 단계는 홈 교체가 아닙니다.
이번 단계는 기존 `home.tsx` 수정이 아닙니다.
이번 단계는 PWA 수정이 아닙니다.
이번 단계는 광고/결제/SNS 기능 구현이 아닙니다.

오직 **새 홈 v2 최소 미리보기 화면**까지만 구현합니다.

## 3. 화면 구성

`/home-v2` 화면은 다음 구조로 만드세요.

### 상단

1. PLAY강릉 로고 또는 텍스트 로고
2. 짧은 설명 문구
3. 검색창

예시 문구:

```text id="w6t9pe"
강릉의 오늘을 한눈에 보는 로컬 소식 플랫폼
```

### 오늘의 강릉소식

데이터:

```text id="2e23kh"
GET /api/top5
```

표시:

1. 섹션 제목: 오늘의 강릉소식
2. 1~5개 카드
3. 순위 뱃지
4. 썸네일
5. 제목
6. 카테고리
7. 출처
8. 클릭 시 `/content/:eventId`

주의:

* 사용자 화면에는 “TOP5”라는 표현을 크게 쓰지 말 것
* 내부 데이터가 top5여도 화면 문구는 “오늘의 강릉소식”으로 표시

### 강릉노트 피드

데이터:

```text id="xenvjf"
GET /api/feed
```

표시:

1. 섹션 제목: 강릉노트
2. 카드 그리드
3. 썸네일
4. 제목
5. 요약
6. 카테고리
7. 출처
8. 클릭 시 `/content/:id`

### 검색/필터

1. 검색 대상: 제목, 설명, 카테고리, 출처
2. 카테고리 필터: 전체, 행사, 맛집, 관광, 지역소식, 기타
3. 필터링은 클라이언트 local state로 처리
4. 새 API 만들지 말 것

<Route path="/home-v2" component={HomeV2Page} />
