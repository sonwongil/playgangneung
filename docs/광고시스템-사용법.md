# PLAY강릉 광고 시스템 사용 가이드

> 광고 접수부터 Meta 집행까지 — 관리자 개입 포인트 중심으로 설명합니다.

---

## 전체 흐름 요약

```
[광고주 신청]
     ↓
[관리자] 신청목록 확인 · AI 검수 실행
     ↓
[관리자] 광고 승인
     ↓
[관리자] 광고풀 생성 · 광고 추가
     ↓
[관리자] 로테이션 편성 · 풀 활성화
     ↓
[선택] Meta 광고 집행
     ↓
[모니터링] 알림 센터 확인
```

---

## STEP 1 — 광고 접수

### 경로 A: 광고주 직접 신청
- 공개 홈페이지 우상단 **"공동광고 지원센터"** 배너 클릭
- 광고주가 업체명 / 카테고리 / 제목 / 설명 / 연락처 / 이미지 입력 후 제출
- 제출 즉시 상태 **`접수대기(pending)`** 로 저장됨

### 경로 B: 관리자 직접 등록
- 대시보드 → **광고센터** → **신청목록** 탭 상단 **"수동 등록"** 버튼
- 모든 항목 직접 입력 가능

### 광고 플랜 구분
| 플랜 | 표시 | 설명 |
|------|------|------|
| `basic` | 광고 | 일반 노출 |
| `main` | 직접광고 | 피드 상단 배치 |
| `premium` | 프리미엄광고 | 상단 슬라이더 고정 노출 |

---

## STEP 2 — 관리자 검토 · AI 검수

**위치**: 대시보드 → **광고센터** → **신청목록** 탭

### 관리자 할 일
1. 신규 접수 건 확인 (상태: `접수대기`)
2. 우상단 **"미검수 광고 일괄 점검"** 버튼 클릭
   - AI가 광고 문구를 자동 검토하여 각 광고에 **점수(0~100점)** 와 **한 줄 코멘트** 부여
   - 대상: aiScore가 없는 광고 / 1회 최대 10건 처리
3. 점수 확인
   - **80점 이상**: 양호 — 바로 승인 가능
   - **60~79점**: 보통 — 검토 후 판단
   - **60점 미만**: 개선 필요 — 광고주에게 수정 요청 권장

### AI 검수가 하는 일 (코치 역할)
- 과장 표현 감점 (최고, 100%, 보장 등)
- 강릉 지역 특색 반영 여부 평가
- 개선 포인트 코멘트 제공
- ※ AI 점수는 노출량에 영향을 주지 않습니다. 광고 품질 개선 도구입니다.

### 개별 광고 AI 문구 보정
- 광고 카드 → **"AI 검수"** 버튼 클릭
- 개선된 제목 / 설명 / 문제점 목록 확인
- 참고하여 광고주에게 수정 요청 또는 직접 편집

---

## STEP 3 — 광고 승인

**위치**: 광고센터 → 신청목록 → 광고 카드 클릭 → 상태 변경

### 상태 흐름
```
접수대기(pending)
  → 승인(approved)     ← 관리자 승인
  → 예약(scheduled)    ← 집행 예약된 상태
  → 게재중(published)  ← 실제 노출 중
  → 거절(rejected)     ← 부적합 광고
```

### ⭐ 프리미엄 슬라이더 노출 설정
- 광고 카드의 **"⭐ 프리미엄"** 버튼 토글
- 활성화 시 공개 홈페이지 최상단 프리미엄 슬라이더에 고정 노출
- `premium` 플랜 광고에만 적용 권장

---

## STEP 4 — 광고풀 생성

**위치**: 광고센터 → **광고풀 생성** 탭

광고풀은 여러 광고를 묶어 24시간 로테이션으로 운영하는 단위입니다.

### 관리자 할 일
1. **"새 광고풀 만들기"** 클릭
2. 풀 이름 입력 (예: "5월 강릉 행사 묶음")
3. 목표 선택
   - `awareness`: 인지도
   - `traffic`: 유입
   - `conversion`: 전환
   - `engagement`: 참여
4. 운영 기간 설정 (시작일 ~ 종료일)
5. 예산 입력
6. **편성 전략(aiMode)** 선택

### 편성 전략 선택 기준
| 전략 | 이름 | 언제 쓰나 |
|------|------|-----------|
| `equal` | 균등 | 기본값. 광고 수 무관 공평하게 배분 |
| `performance` | 성과형 | 피크타임(9~21시) 포함, 계약 기준 균등 순환 |
| `overexposure_prevention` | 과노출 방지 | 동일 광고 연속 2시간 이상 방지 |
| `new_ad_boost` | 신규 부스트 | 새로 등록된 광고 피크타임 우선 배치 |
| `manual` | 수동 | 관리자가 직접 슬롯 지정 |

7. 승인된 광고 목록에서 이 풀에 포함할 광고 선택 후 추가

---

## STEP 5 — 로테이션 편성 · 풀 활성화

**위치**: 광고센터 → **로테이션** 탭

### 관리자 할 일
1. 풀 선택
2. **"AI 편성표 생성"** 클릭
   - 선택한 전략에 따라 24시간(0~23시) 슬롯 자동 배정
   - 각 슬롯에 어떤 광고가 배치되는지 표로 확인 가능
3. 편성 결과 확인 후 문제 없으면 풀 상태를 **`active`** 로 변경

---

## STEP 6 — Meta 광고 집행 (선택)

**위치**: 광고센터 → **Meta 연동** 탭

플레이강릉 페이스북/인스타그램 공식 페이지에 광고를 자동 집행합니다.

### 사전 조건
- 풀 상태: `active`
- 풀에 승인된 광고 최소 1건 이상
- Meta 환경변수 정상 설정 (이미 완료)

### 관리자 할 일
1. 풀 선택
2. **"Meta에 집행"** 버튼 클릭
3. 자동 처리 순서:
   - 캠페인 생성 (Meta Business)
   - 광고세트 생성
   - 이미지 업로드
   - 광고 소재(Creative) 생성
   - 광고 집행 시작
4. 집행 완료 후 `metaCampaignId` / `metaAdSetId` 풀에 저장됨
5. Meta Business Suite에서 성과 확인 가능

---

## STEP 7 — 모니터링

**위치**: 광고센터 → **개요** 탭 or **알림 센터**

### 알림 종류 및 대응
| 알림 종류 | 의미 | 대응 |
|-----------|------|------|
| `ai_score_low` | AI 점수 60점 미만 광고 | 광고주에게 문구 수정 요청 |
| `pending_long` | 2일 이상 대기 중 | 승인 또는 거절 처리 |
| `pool_expired` | 운영 기간 종료된 풀 | 풀 상태 `ended`로 변경 |
| `overexposure` | 동일 광고 3시간 이상 연속 노출 | 로테이션 편성 재생성 |
| `low_ctr` | CTR 0.5% 미만 (100노출 이상) | 광고 소재(이미지·문구) 교체 권장 |
| `budget_burn_fast` | 예산 소진 속도 이상 | 예산 증액 또는 일정 조정 |

### 알림 감지 실행
- 광고센터 → 개요 → **"알림 감지"** 버튼 클릭 (수동 실행)
- 감지된 알림은 목록에 표시 → 처리 후 **"해제"** 클릭

---

## 성과 확인

**위치**: 광고센터 → **성과** 탭

- 풀 선택 → 기간 설정 → 노출 / 클릭 / CTR / 지출 확인
- 수동 성과 입력도 가능 (Meta 외 지면 성과 기록용)

---

## 자주 쓰는 작업 요약

| 작업 | 위치 |
|------|------|
| 신규 접수 확인 | 광고센터 → 신청목록 |
| AI 일괄 점검 | 신청목록 상단 버튼 |
| 광고 승인/거절 | 광고 카드 클릭 → 상태 변경 |
| 프리미엄 슬라이더 노출 | 광고 카드 ⭐ 프리미엄 버튼 |
| 광고풀 만들기 | 광고센터 → 광고풀 생성 |
| 로테이션 편성 | 광고센터 → 로테이션 |
| Meta 집행 | 광고센터 → Meta 연동 |
| 알림 확인 | 광고센터 → 개요 |

---

## 노출 정책 원칙

- **모든 광고는 계약(플랜) 기준으로 공정하게 노출됩니다.**
- AI 점수는 노출량을 늘리거나 줄이지 않습니다.
- AI는 광고 품질 개선을 돕는 코치 역할만 합니다.
- 광고주는 구매한 플랜만큼 반드시 노출됩니다.
