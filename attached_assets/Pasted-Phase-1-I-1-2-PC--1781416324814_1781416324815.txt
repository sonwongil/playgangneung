# Phase 1-J 승인 범위

## 운영 홈 사용자 관점 경미한 보정

## 1. 수정 목표

오늘 바로 수정할 항목은 아래 2개만입니다.

### P1. 소상공인 추천 섹션 빈 상태 처리

현재 문제:

```text
소상공인 추천 데이터가 없는데
"🏪 소상공인 추천 강릉 지역 업체" 제목만 노출됨
```

수정 방향:

```text
premiumAds.length === 0이면
소상공인 추천 섹션 제목까지 전체 숨김
```

즉, 카드가 없을 때 제목만 보이지 않게 하세요.

---

### P2. PC 검색창 좌편향 완화

현재 문제:

```text
PC에서 검색창이 로고 바로 옆에서 시작해 왼쪽으로 치우쳐 보임
오른쪽 공간은 비어 있고 버튼만 멀리 떨어져 보여 시각적 무게 중심이 어색함
```

수정 방향:

```text
PC 검색창 wrapper에 mx-auto 또는 적절한 중앙 정렬 보정 적용
단, 모바일 2행 구조는 유지
```

주의:

1. 모바일 검색창 `w-full` 구조는 건드리지 마세요.
2. PC에서만 검색창이 좀 더 중앙에 오도록 보정하세요.
3. 버튼과 로고가 밀리지 않도록 기존 `shrink-0`, `flex-1`, `max-w-xl` 원칙은 유지하세요.

---

## 2. 이번 단계에서 건드리지 않을 것

아래는 이번 단계에서 수정하지 마세요.

1. 강릉노트 빈 상태 문구
2. 강릉노트 데이터 로직
3. `/content/:id` 상세페이지
4. 광고문의 배너
5. 푸터
6. 로그인/광고접수 버튼
7. 카테고리 탭
8. `/home-legacy`
9. `/admin`
10. `/admin/v2`

강릉노트 빈 상태는 현재 운영 데이터 부족 성격이 강하므로, 오늘은 코드 수정하지 않습니다.
