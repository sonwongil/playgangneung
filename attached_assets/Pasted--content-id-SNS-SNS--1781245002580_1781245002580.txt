`/content/:id` 강릉노트에서 관리자 로그인 상태인데도 `SNS 공유 관리` 버튼이 보이지 않는 문제를 수정해 주세요.

현재 상태:

* 일반 방문자에게 SNS 공유 패널이 숨겨지는 것은 정상입니다.
* 하지만 관리자 로그인 후 `/content/:id`에 접속해도 `🛠️ SNS 공유 관리` 버튼이 보이지 않습니다.
* 즉, 비관리자 숨김은 성공했지만 관리자 판별이 실패하고 있습니다.

문제 추정:

* 현재 `content.ts`에서 `const isAdmin = req.session?.isAdmin === true;` 기준으로 판단하고 있습니다.
* 그런데 실제 관리자 로그인 상태가 이 세션 값에 저장되지 않거나, `/content/:id` 서버 요청에서 해당 세션이 전달되지 않는 것 같습니다.
* `/admin` 화면에서 사용하는 실제 관리자 인증 방식과 `/content/:id`의 관리자 판별 방식이 일치해야 합니다.

수정 목표:

1. `/content/:id`에서 관리자 로그인 상태를 정확히 인식해야 합니다.
2. 일반 방문자에게는 SNS 공유 관리 버튼과 패널이 계속 숨겨져야 합니다.
3. 관리자 로그인 상태에서는 작은 `🛠️ SNS 공유 관리` 버튼이 보여야 합니다.
4. 버튼 클릭 전에는 패널이 숨김 상태여야 합니다.
5. 버튼 클릭 후에만 SNS 공유 패널이 펼쳐져야 합니다.

확인할 것:

1. `/api/auth/login` 성공 시 실제로 어떤 세션 값 또는 쿠키 값이 저장되는지 확인해 주세요.
2. `/admin` 접근 권한을 판단하는 기존 미들웨어 또는 로직을 확인해 주세요.
3. `requireAdmin` 또는 관리자 체크에 사용되는 실제 기준과 `content.ts`의 기준이 같은지 확인해 주세요.
4. 만약 기존 관리자 인증이 `req.session.isAdmin`이 아니라 다른 값, 예를 들어 `req.session.admin`, `req.session.user`, `req.session.role`, 별도 쿠키, 토큰 등이라면 `/content/:id`도 동일한 기준을 사용하게 수정해 주세요.
5. 가능하면 관리자 판별 함수를 공통화해서 `/admin`과 `/content/:id`가 같은 기준을 쓰도록 해 주세요.
