# Phase 1-F3 승인 범위

## `/home-v2` 광고문의 배너 추가

이번 단계의 목표는 `/home-v2` 안에 PLAY강릉의 사업 목적을 보여주는 광고문의/제휴문의 배너를 추가하는 것입니다.

PLAY강릉은 단순 지역 소식 사이트가 아니라
강릉 소상공인의 온라인 마케팅을 돕는 플랫폼입니다.

따라서 새 홈에는 사용자가 자연스럽게 광고문의 또는 제휴문의로 이동할 수 있는 안내 영역이 필요합니다.

이번 단계는 광고 신청 기능 구현이 아닙니다.
이번 단계는 결제 기능 구현이 아닙니다.
이번 단계는 Meta 광고 기능 구현이 아닙니다.
이번 단계는 기존 `/` 홈 교체가 아닙니다.

오직 **`/home-v2` 안에 광고문의 배너를 읽기 전용으로 추가**하는 작업입니다.

---

## 1. 허용 작업

다음 작업만 허용합니다.

1. `HomeV2Page.tsx` 안에 광고문의 배너 섹션 추가
2. 기존 `GET /api/joint-ad-modal` 또는 `GET /api/banner-config`를 읽기 전용으로 사용할 수 있으면 사용
3. API 구조가 불명확하면 정적 문구로 우선 구성
4. 배너 위치는 소상공인 추천 섹션 아래, 강릉노트 피드 위 또는 페이지 하단 중 선택
5. 문구는 간단하고 명확하게 작성
6. 버튼은 “광고 문의하기” 또는 “제휴 문의하기”로 표시
7. 버튼 클릭은 아직 실제 신청 기능으로 연결하지 말고 placeholder 처리
8. 안전한 기존 광고문의 경로가 이미 있으면 해당 경로만 사용
9. typecheck 실행
10. build 실행

## 2. 추천 배너 문구

다음 방향으로 구성하세요.

```text
강릉 소상공인을 위한 온라인 홍보가 필요하신가요?

PLAY강릉은 지역 소식, 강릉노트, 소상공인 추천 카드, SNS 광고를 연결해
작은 가게도 쉽게 온라인 홍보를 시작할 수 있도록 돕습니다.
```

버튼 문구:

```text
광고 문의하기
```

또는

```text
제휴 문의하기
```
