이번 단계의 목표는 `/admin/v2/today`에서 저장된 `daily_top5`가 정상적으로 다시 조회되고,
기존 홈 상단에 노출될 때 어떤 카드 구성으로 보일지 관리자 화면 안에서 미리 확인하는 것입니다.

이번 단계는 “홈 리빌딩”이 아닙니다.
이번 단계는 “SNS 발행”이 아닙니다.
이번 단계는 “Meta 광고 확장”이 아닙니다.
이번 단계는 “기존 home.tsx 수정”이 아닙니다.

오직 **저장 결과 확인과 관리자용 미리보기**까지만 구현합니다.

## 3. 미리보기 화면 구성

`/admin/v2/today` 하단 또는 우측에 다음 영역을 추가하세요.

### 저장된 오늘의 강릉소식 미리보기

표시 항목:

1. 날짜
2. 저장된 개수
3. 1~5번 카드
4. 각 카드의 썸네일
5. 제목
6. 카테고리
7. 출처
8. 원본 URL
9. `/content/:id` 상세보기 링크가 있으면 표시

안내 문구:

```text
이 영역은 관리자용 미리보기입니다.
기존 홈 화면 코드는 수정하지 않았습니다.
```

---

## 4. 일치 여부 표시

저장 후 재조회된 top5와 현재 화면 슬롯이 일치하는지 확인 표시를 추가하세요.

예:

```text
저장 상태: 현재 선택과 저장된 데이터가 일치합니다.
```

또는

```text
저장 상태: 현재 선택이 저장된 데이터와 다릅니다. 저장이 필요합니다.
```

이 비교는 화면 내부 계산만 사용하세요.
새 API를 만들지 마세요.
