원인은 거의 확정입니다.
단오제 카드만 “처음부터 정상적인 외부 이미지 URL을 갖고 들어오지 않았기 때문”입니다.

다른 카드들은 대부분 이런 형태였습니다.

https://www.kwnews.co.kr/photos/...
https://img9.yna.co.kr/photo/...
https://www.gncaf.or.kr/...
즉, 처음부터 완전한 이미지 주소였습니다.

그런데 단오제 카드는 원본 사이트에서 이미지가 이렇게 들어왔습니다.

/image/logo_2026.png
이건 완전한 주소가 아닙니다.
쉽게 말하면 “사진 주소 전체”가 아니라 “사이트 안의 일부 경로”만 들어온 겁니다.

정상이라면 이렇게 바뀌어야 했습니다.

https://www.danojefestival.or.kr/image/logo_2026.png
그런데 시스템이 이걸 제대로 보정하지 못하고 그대로 DB에 저장했습니다.

그래서 단오제 카드만 생긴 흐름
정확히는 이런 순서입니다.

1. 단오제 원본 사이트 og:image가 /image/logo_2026.png 상대경로로 들어옴
2. PLAY강릉 DB thumbnail에 그 값이 그대로 저장됨
3. 홈 화면이 이걸 이미지로 표시하려고 함
4. proxyImg가 /image/logo_2026.png를 외부 이미지처럼 잘못 처리함
5. /api/proxy/image?url=%2Fimage%2Flogo_2026.png 로 요청됨
6. proxy는 상대경로를 처리 못해서 400 발생
7. 이미지 실패
8. fallback 로고 또는 이모지 표시
그 후 리플릿이 여러 번 고치면서 더 꼬였습니다.

thumbnail null 처리
→ 이모지 표시

/api/uploads/... 직접 업로드
→ 개발 서버에는 있음
→ 운영 서버에는 없음
→ 404

kwnews URL 저장했다고 보고
→ 실제 운영 /api/top5 확인 결과 thumbnail은 여전히 null
그래서 지금 현재 운영 API 기준으로는 단오제 카드가 이렇게 내려오고 있습니다.

rank: 4
eventId: 01a8ca6c7372e67bae623aae3942ed6b
thumbnail: null
즉 홈 화면이 잘못한 게 아니라, API가 4번 카드에 줄 이미지가 없다고 말하고 있는 상태입니다.

왜 다른 카드는 괜찮고 단오제만 문제냐?
차이는 딱 이겁니다.

카드	이미지 상태	결과
1번	Instagram CDN 절대 URL	정상
2번	기관/외부 절대 URL	정상
3번	연합뉴스 절대 URL	정상
4번 단오제	처음에 /image/logo_2026.png 상대경로 → 이후 null	문제
5번	연합뉴스 절대 URL	정상
단오제 카드만 상대경로 이미지 + 수동 수정 이력 + 운영 DB 미반영이 겹친 겁니다.

진짜 원인 한 줄 요약
단오제 원본 사이트의 이미지 주소가 완전한 URL이 아니라 /image/logo_2026.png 같은 상대경로였고, 이걸 PLAY강릉이 저장 전에 정상 URL로 바꾸지 못해서 시작된 문제입니다.

거기에 리플릿이 임시로 이미지를 넣고, 지우고, /api/uploads를 쓰고, 다시 null로 만들면서 문제가 길어진 겁니다.

지금 해결은 단순합니다
코드 더 건드리지 말고, 운영 DB의 단오제 이벤트에 대표 이미지만 정확히 넣으면 됩니다.

이벤트 ID:
01a8ca6c7372e67bae623aae3942ed6b

해야 할 일:
thumbnail에 실제 이미지 URL 저장

확인:
https://playgangneung.com/api/top5 에서 rank 4 thumbnail이 null이 아니어야 함
예를 들면 이렇게 되어야 합니다.

thumbnail: "https://www.kwnews.co.kr/photos/2026/06/01/2026060150028300000_l.jpg"
또는 관리자가 직접 올린 이미지가 운영에서 유지되는 저장소에 있다면:

thumbnail: "운영에서 접근 가능한 이미지 URL"
하지만 현재 /api/uploads/...는 운영 배포에서 사라질 수 있으니 지금은 쓰지 않는 게 맞습니다.

리플릿에게 이렇게 말하면 됩니다
단오제 카드만 문제가 생긴 원인은 원본 og:image가 `/image/logo_2026.png` 상대경로였고, 이 값이 정상 절대 URL로 정규화되지 않은 채 thumbnail에 저장되었기 때문입니다.

현재 운영 API `/api/top5`를 직접 확인하면 rank 4 단오제 카드의 thumbnail이 null입니다.

따라서 지금 할 일은 코드 수정이 아니라 운영 DB의 해당 이벤트 thumbnail 값을 정상 이미지 URL로 저장하는 것입니다.

이벤트 ID:
01a8ca6c7372e67bae623aae3942ed6b

요구사항:
1. 운영 DB에서 해당 이벤트 thumbnail을 실제 접근 가능한 이미지 URL로 저장
2. `/api/top5` rank 4 thumbnail이 null이 아닌지 확인
3. 홈 화면 rank 4 카드에 이미지가 표시되는지 확인
4. extraImages, Object Storage, DB 스키마, 프론트 코드는 건드리지 말 것
결론적으로, 단오제 카드만 이상한 이유는 처음 들어온 이미지 주소의 품질이 달랐기 때문입니다. 다른 카드들은 완전한 이미지 URL이었고, 단오제는 불완전한 상대경로였습니다.
