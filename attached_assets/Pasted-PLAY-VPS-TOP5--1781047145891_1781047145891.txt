PLAY강릉 VPS 전환 이후 기능 개선을 이어갑니다.

아직 코드 수정하지 말고, 먼저 현재 구조 분석과 설계안만 작성해 주세요.

이번 작업의 핵심은 TOP5 링크 문제를 단순히 원본 링크로 바꾸는 것이 아닙니다.
PLAY강릉의 “카드” 구조와 “강릉노트” 구조를 함께 정리하는 것입니다.

용어 정리:

1. “카드”는 PLAY강릉 홈/목록/TOP5에 보이는 섬네일형 콘텐츠 단위이면서, Facebook/Instagram 등 SNS에 공유·발행될 수 있는 피드형 콘텐츠 단위를 의미합니다.
2. “강릉노트”는 /content/:id 페이지를 의미합니다.
3. 강릉노트는 블로그형 긴 글이 아니라, 구글과 AI가 이해하기 쉬운 카드형 상세 정보 페이지입니다.
4. 강릉노트는 날짜, 장소, 요약, 출처 URL, 추천 이유, 카테고리, 지도, 예약/문의 버튼, 원본보기 버튼 등을 담는 PLAY강릉 자체 검색 자산입니다.

중요한 방향:

/content/:id 페이지는 삭제하면 안 됩니다.
이 페이지는 앞으로 강릉노트 상세 페이지로 개선해야 합니다.

다만 현재 /content/:id가 단순히 원본 링크를 한 번 더 보여주는 중간 페이지처럼 보이면 사용자 경험이 좋지 않습니다.
따라서 강릉노트가 실제 정보 가치가 있는 상세 페이지가 되도록 구조를 설계해 주세요.

확인할 것:

1. 현재 /content/:id 라우트가 어떤 프론트 컴포넌트에서 처리되는지 확인해 주세요.
2. /content/:id 페이지가 어떤 API를 호출하는지 확인해 주세요.
3. TOP5 카드 클릭 href가 어디에서 결정되는지 확인해 주세요.
4. 일반 피드 카드 클릭 href가 어디에서 결정되는지 확인해 주세요.
5. SNS 공유/발행용 데이터가 현재 카드 데이터와 어떻게 연결되어 있는지 확인해 주세요.
6. sourceUrl, link, originalUrl, reservationUrl, advertiserUrl 성격의 필드가 현재 DB/API에 있는지 확인해 주세요.
7. 현재 필드만으로 linkMode 정책을 처리할 수 있는지 확인해 주세요.
8. 부족하다면 linkMode 필드 추가 설계만 제안하고, 아직 DB schema 변경은 하지 마세요.
9. 일반 피드, TOP5, 광고 카드, SNS 공유 카드가 같은 링크 정책을 공유할 수 있는지 확인해 주세요.
10. iframe 방식은 어떤 사이트에서 가능한지, 불가능할 때 원본보기 버튼으로 대체 가능한지 검토해 주세요.
11. PC 뒤로가기 문제를 linkMode 정책과 함께 어떻게 해결할지 검토해 주세요.

링크 정책 설계 방향:

각 카드에는 linkMode 개념이 필요합니다.

예시:

* linkMode=note
  카드 클릭 시 /content/:id, 즉 강릉노트로 이동

* linkMode=source
  카드 클릭 시 외부 원본 URL로 이동

* linkMode=ad_landing
  카드 클릭 시 광고용 강릉노트로 이동

* linkMode=external_ad
  카드 클릭 시 광고주 홈페이지/예약/스마트스토어/인스타그램 등 외부 링크로 이동

* linkMode=iframe
  PLAY강릉 내부 프레임으로 원본 표시
  단, iframe 허용 사이트만 제한적으로 적용

TOP5 정책:

1. TOP5 카드 클릭 기본값은 강릉노트 /content/:id 로 둡니다.
2. 단, 관리자가 linkMode=source로 지정한 경우에는 원본 URL로 바로 이동할 수 있어야 합니다.
3. TOP5 카드 안에는 “강릉노트 보기”, “원본 보기”, “예약/신청하기” 버튼을 분리하는 방향으로 설계해 주세요.
4. 예약/신청 URL이 있으면 별도 버튼으로 제공해야 합니다.
5. TOP5에서 새로운 카드에 밀려난 기존 카드는 삭제하거나 숨기지 말고, TOP5 아래 일반 카드 목록에 계속 노출되어야 합니다.

홈 카드 누적 정책:

1. 상단에는 현재 TOP5 카드 5개를 보여줍니다.
2. TOP5 아래에는 현재 TOP5를 제외한 최신 승인 카드 약 60개를 보여줍니다.
3. 과거 TOP5였지만 현재 TOP5가 아닌 카드는 일반 카드 목록에 포함되어야 합니다.
4. 60개 이전 카드는 페이지네이션 또는 더보기 방식으로 계속 접근 가능해야 합니다.
5. 정렬 기준은 approvedAt DESC를 우선 검토하고, 없으면 createdAt DESC를 사용합니다.
6. draft 상태의 카드는 홈, TOP5, 일반 카드 목록, SNS 발행 대상 어디에도 노출하지 않습니다.

강릉노트 상세 페이지 설계 방향:

/content/:id 페이지는 다음 정보를 담는 구조로 개선해야 합니다.

* 대표 이미지 또는 카드뉴스 이미지 3~5장
* 제목
* 한 줄 요약
* 날짜
* 장소
* 운영시간
* 가격
* 문의
* 카테고리
* 출처 URL
* 지도
* 추천 이유 5~7줄
* 원본보기 버튼
* 예약/신청/문의 버튼
* 관련 콘텐츠
* 주변 맛집 또는 주변 행사
* 공유 버튼
* 저장 버튼

SEO 관점에서 이미지 안의 문구는 반드시 HTML 텍스트로도 제공되어야 합니다.
제목, 요약, 날짜, 장소, 카테고리, 출처 URL, 추천 이유는 검색엔진과 AI가 이해할 수 있는 텍스트 필드로 유지되어야 합니다.
