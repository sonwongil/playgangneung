# 수정 항목

## 1. 소상공인 추천 섹션 제목 변경

`premiumAds.length > 0`일 때 표시되는 섹션 제목을 아래처럼 변경하세요.

```text id="krnzg6"
기존: 소상공인 추천
변경: 강릉시 소상공인추천
```

데이터가 0건일 때 섹션 전체가 숨겨지는 기존 Phase 1-J 수정은 유지하세요.

---

## 2. 소상공인 추천 섹션 빈 상태 처리 유지 확인

아래 조건이 유지되어야 합니다.

```text id="4du96u"
로딩 중: 제목 + 스켈레톤 표시 가능
로딩 완료 후 premiumAds.length === 0: 섹션 제목 포함 전체 숨김
premiumAds.length > 0: 제목 + 카드 표시
```

---

## 3. PC 검색창 중앙 정렬 유지 확인

이전 수정 내용이 유지되어야 합니다.

```text id="r69omk"
PC: 로고와 버튼 사이 공간 안에서 검색창 중앙 정렬
모바일: 2행 구조, 검색창 w-full 유지
```

모바일 구조는 건드리지 마세요.

---

## 4. 강릉노트 빈 상태 문구만 경미하게 개선

운영에서 강릉노트 데이터가 없을 때 화면이 허전하므로, 기능 로직은 바꾸지 말고 문구만 부드럽게 바꾸세요.

예시:

```text id="r4ko0h"
기존: 아직 등록된 컨텐츠가 없습니다.
변경: 강릉의 새로운 소식을 준비하고 있습니다.
보조문구: 곧 더 많은 강릉노트가 업데이트됩니다.
```

주의:

1. API 로직 변경 금지
2. 데이터 조건 변경 금지
3. DB 수정 금지
4. 빈 상태 디자인을 과하게 키우지 말 것
5. 문구와 여백 정도만 가볍게 보정

---

## 5. 문구 표기 통일

아래 표현을 점검하고 가능하면 통일하세요.

```text id="334ycp"
컨텐츠 → 콘텐츠
소상공인 추천 → 강릉시 소상공인추천
```

단, 광범위한 파일 검색/수정은 하지 말고 `HomeV2Page.tsx` 내부에 있는 문구만 정리하세요.
