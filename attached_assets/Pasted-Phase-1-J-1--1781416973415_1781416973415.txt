## 2. VPS 운영 반영

GitHub push 성공 후 VPS에서 아래 순서로 진행합니다.

### 2-1. VPS 현재 상태 확인

```bash id="ba3sq6"
cd /var/www/playgangneung
git status --short -uno
git rev-parse HEAD
pm2 status
```

확인 기준:

```text id="8eqjza"
추적 중인 파일 수정 없음
PM2 앱 playgangneung online
mode fork 유지
```

---

### 2-2. 운영 백업

```bash id="ou9ngc"
ls -ld /var/www/backups 2>/dev/null || mkdir -p /var/www/backups

tar -czf /var/www/backups/playgangneung-before-phase1j-$(date +%Y%m%d-%H%M%S).tar.gz \
  --exclude='/var/www/playgangneung/node_modules' \
  --exclude='/var/www/playgangneung/.pnpm-store' \
  -C /var/www playgangneung

ls -lh /var/www/backups/ | tail -5
```

---

### 2-3. pull

```bash id="wak5zo"
cd /var/www/playgangneung
git fetch origin main
git log --oneline HEAD..origin/main
git pull origin main
git rev-parse HEAD
```

### 2-4. build

