PLAY강릉 프로젝트에 “광고접수” 기능을 추가해줘.

현재 프로젝트:
- React + Vite 프론트
- Express 백엔드
- 관리자 대시보드 존재
- 공개 메인 피드 존재
- 상단 탭:
  전체 / 행사 / 맛집 / 핫플 / 지역소식

-----------------------------------
1. 메인 탭에 광고접수 추가
-----------------------------------

현재 상단 카테고리 탭에:
“광고접수” 탭 추가

순서:
전체 / 행사 / 맛집 / 핫플 / 지역소식 / 광고접수

탭 클릭 시:
/ad-submit 페이지로 이동

탭 디자인:
- 기존 탭 스타일 유지
- 파란색 active 상태 유지
- 모바일 최적화

선택된 상품은 form plan 값으로 저장:

9. 백엔드 API 추가
-----------------------------------

POST /api/ads

광고 저장 구조:
{
  id,
  businessName,
  contactName,
  phone,
  email,
  category,
  title,
  description,
  date,
  location,
  url,
  imageUrl,
  plan,
  status: "pending",
  source: "광고접수",
  createdAt,
  isFreeAd: true
}

GET /api/ads
PATCH /api/ads/:id/status
DELETE /api/ads/:id

-----------------------------------
12. 중요 디자인 방향
-----------------------------------

이 페이지는 “광고 관리자” 느낌보다
“강릉 콘텐츠 등록 플랫폼” 느낌이 중요하다.

사용자가 어렵지 않게:
- 제목 입력
- 사진 업로드
- 내용 작성
- 등록

할 수 있어야 한다.

UI는:
네이버 스마트플레이스 등록 + 인스타 업로드 화면 느낌 참고.

가능하면 github의 modern upload form 스타일 차용 가능.
