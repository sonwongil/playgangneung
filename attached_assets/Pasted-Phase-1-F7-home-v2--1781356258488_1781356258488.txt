# Phase 1-F8 승인 범위

## `/home-v2`를 `/`로 교체하고 기존 홈은 `/home-legacy`로 보존

이번 단계의 목표는 새 홈을 메인 `/` 경로로 연결하되, 기존 홈을 삭제하지 않고 `/home-legacy`로 보존하는 것입니다.

이번 단계는 기존 `home.tsx` 삭제가 아닙니다.
운영 서버 수정이 아닙니다.
GitHub push가 아닙니다.
DB/API/PWA 수정이 아닙니다.

오직 **프론트 라우트 교체**만 진행합니다.

---

## 1. 허용 작업

다음 작업만 허용합니다.

1. `App.tsx` 라우트만 수정
2. 기존 `/` 라우트의 component를 `Home`에서 `HomeV2Page`로 변경
3. 기존 `Home`은 `/home-legacy` 라우트로 보존
4. 기존 `/home-v2` 라우트는 유지하거나 제거 여부를 보고 후 결정
5. 기존 `home.tsx` 파일 삭제 금지
6. 기존 `Home` import 삭제 금지
7. typecheck 실행
8. build 실행

---

## 2. 권장 라우트 구조

현재:

```tsx
<Route path="/" component={Home} />
<Route path="/home-v2" component={HomeV2Page} />
```

변경 후 권장:

```tsx
<Route path="/" component={HomeV2Page} />
<Route path="/home-v2" component={HomeV2Page} />
<Route path="/home-legacy" component={Home} />
```

`/home-v2`는 당분간 유지해도 됩니다.
이유는 교체 직후 비교와 확인이 쉽기 때문입니다.

최종 안정화 후 `/home-v2`는 제거 가능합니다.
