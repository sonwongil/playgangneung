Phase 1-L에서 남겨둔 attached_assets 내부 이미지 파일 중 앱 코드에서 참조되지 않는 작업용 이미지/스크린샷류를 정리합니다.

중요:
이번 단계에서도 GitHub push 금지, VPS 배포 금지, PM2 restart 금지입니다.
기능 수정, UI 수정, DB 수정은 하지 않습니다.
저장소 정리만 진행합니다.

사업자등록증 PDF는 공개용 자료로 판단하여 이번 단계에서는 삭제하지 않습니다.

절대 금지:

* git add .
* git push
* VPS 배포
* PM2 restart
* DB, nginx, SSL, PWA, Service Worker, Meta API, 결제 기능 수정
* package.json, pnpm-lock.yaml 수정
* drizzle/migration 파일 수정
* HomeV2Page.tsx, App.tsx, home.tsx 수정
* ecosystem.config.cjs 수정
* public/* 수정
* uploads/* 수정
* backups/* 수정
* dist/* 수정

작업 순서:

1. attached_assets 현재 파일 목록 확인

```bash
find attached_assets -maxdepth 3 -type f | sort
```

2. 이미지 파일 목록 분류

```bash
find attached_assets -maxdepth 2 -type f \( -iname "*.png" -o -iname "*.jpg" -o -iname "*.jpeg" -o -iname "*.webp" \) | sort
```

3. 코드 참조 여부 확인

```bash
grep -R "attached_assets" -n \
  artifacts/playgangneung-dashboard/src \
  artifacts/api-server/src \
  src \
  server \
  public \
  2>/dev/null || true
```

4. 파일명 패턴별 참조 여부 확인

```bash
grep -R "image_\|KakaoTalk_\|Screenshot_\|targeted_element_\|한줄LOGO\|logo_\|자세히보기\|팔로우\|캠페인" -n \
  artifacts/playgangneung-dashboard/src \
  artifacts/api-server/src \
  src \
  server \
  public \
  2>/dev/null || true
```

5. 삭제 가능 후보

코드 참조가 없으면 아래 파일은 삭제합니다.

```text
attached_assets/image_*.png
attached_assets/KakaoTalk_*.jpg
attached_assets/Screenshot_*.jpg
attached_assets/targeted_element_*.png
```

삭제 이유:

* 작업 중 Replit 또는 캡처 과정에서 생성된 이미지 가능성이 높음
* 앱 코드 참조 없음
* 운영 화면에서 직접 사용하는 정적 자산이 아님

6. 이번 단계에서 유지할 파일

아래 파일은 삭제하지 않습니다.

```text
attached_assets/플레이강릉사업자등록증_*.pdf
attached_assets/google*.html
attached_assets/한줄LOGO_*.png
attached_assets/logo_*.png
attached_assets/자세히보기_*.png
attached_assets/팔로우_*.png
attached_assets/캠페인_*.png
```

유지 이유:

* 사업자등록증 PDF는 공개용 자료로 판단
* Google 인증 html은 실제 사용 여부가 불명확하므로 별도 판단 전 유지
* 로고/버튼/캠페인 이미지는 향후 디자인 자료로 재사용 가능성이 있음

7. 삭제 후 상태 확인

```bash
git status --short
```

8. 검증 실행

```bash
pnpm typecheck
pnpm build
```

가능하면 기존 검증 스크립트도 실행합니다.

```bash
bash scripts/validate.sh
```
