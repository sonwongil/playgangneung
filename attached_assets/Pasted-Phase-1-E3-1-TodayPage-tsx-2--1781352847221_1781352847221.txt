## 4. 새 홈 CSS 원칙

새 홈은 Tailwind + shadcn/ui 기준으로 설계하세요.

다음 원칙을 적용합니다.

1. 전역 CSS 추가 최소화
2. 페이지별 CSS 파일 남발 금지
3. 카드 스타일은 컴포넌트 내부 className으로 관리
4. 반복 스타일은 공통 컴포넌트화
5. 모바일 우선
6. PC는 최대 폭 1100~1200px
7. 과도한 애니메이션 금지
8. 이미지 비율 통일
9. 버튼 터치 영역 44px 이상
10. PWA safe-area는 별도 단계에서 처리
